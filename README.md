# 🧠 Jogo da Memória - ODS

Um jogo da memória interativo e educativo, desenvolvido em React, que tem como objetivo ensinar e reforçar o conhecimento sobre os **Objetivos de Desenvolvimento Sustentável (ODS)** da ONU.

## 🎯 Objetivos Educacionais

Este jogo foi criado para promover a conscientização e familiarização com os seguintes ODS:

- **ODS 4**: Educação de Qualidade
- **ODS 6**: Água Potável e Saneamento
- **ODS 7**: Energia Limpa e Acessível
- **ODS 13**: Ação Contra a Mudança Global do Clima

*Podendo ser implementada outras opções*

## 🎮 Como Jogar

1.  **Início**: O jogo começa automaticamente com as cartas embaralhadas.
2.  **Objetivo**: Clique em duas cartas para virá-las e encontrar os pares correspondentes (o nome do ODS e seu número).
3.  **Vitória**: O jogo termina quando todos os pares forem encontrados.
4.  **Recomeçar**: Clique em "Jogar Novamente" para embaralhar e começar uma nova partida.

## 🚀 Tecnologias Utilizadas

- **React**: Biblioteca principal para a construção da interface.
- **Vite**: Ferramenta de build para um desenvolvimento rápido e otimizado.
- **CSS3**: Estilização moderna e animações 3D de alta performance.
- **HTML5**: Estrutura semântica do projeto.

## 🎨 Características

### ✨ Funcionalidades

-   Sistema de "match" de pares com lógica completa.
-   Embaralhamento automático das cartas a cada nova partida.
-   Feedback visual imediato para pares corretos e incorretos.
-   Tela de vitória parabenizando o jogador.

### 🎭 Elementos Visuais

-   Design moderno e responsivo, com um tema escuro e elegante.
-   Cores vibrantes e oficiais de cada ODS para fácil identificação.
-   Animação 3D fluida ao virar as cartas, criando uma experiência tátil.
-   Fonte profissional (Poppins) para melhor legibilidade.
-   Efeitos de `hover` que dão vida à interface.

## 🛠️ Como Executar

### Pré-requisitos

-   Node.js (versão 14 ou superior)
-   NPM ou Yarn

### Instalação e Execução

```bash
# Clone o repositório
git clone [https://github.com/dinarteefilho/jogo-da-memoria-ODS.git](https://github.com/dinarteefilho/jogo-da-memoria-ODS.git)

# Instale as dependências
npm install

# Execute em modo de desenvolvimento
npm run dev

# Gere a build para produção
npm run build

# Visualize a versão de produção localmente
npm run preview
```
## 🎓 Valor Educativo

### Aprendizados Proporcionados:

-   **Consciência sobre os ODS**: Apresenta de forma lúdica alguns dos principais objetivos globais da ONU.
-   **Exercício Cognitivo**: Estimula a memória e a concentração.
-   **Associação Visual**: Ajuda a conectar o nome de cada ODS ao seu número e cor.
